# LLM 分段實作規格

## 目標

讓每個翻譯 Preset 可選擇是否由 LLM 將全文句子分組成段落，並以分段翻譯結果建立文章段落。未啟用時維持現有翻譯流程。

## Preset 與介面

- Preset 增加 `llmSegmentationEnabled` 布林欄位，預設 `false`。
- 欄位持久化於 Preset JSON；載入舊資料時，缺少欄位視為 `false`。
- Preset 編輯頁在「自訂提示詞」標題列新增開關，放在預覽 icon 左側。
- 新增、既有、複製及內建「預設翻譯」Preset 均可設定；複製時沿用原值。
- 內建 Preset 的名稱、提示詞、詞彙維持不可編輯，僅此開關可切換。
- Preset 預覽在開關啟用時，於自訂提示詞之後、字彙表之前插入分段輸出格式提示。

## 翻譯流程

- 選擇 Google 翻譯時忽略此設定；只對 Gemini 與 ChatGPT 生效。
- 啟用時，使用 `ArticleSegmenter` 的句子規則建立按原文順序排列的句子清單，並將未以句尾標點結束的尾段保留為最後一句。
- 將完整句子清單以 JSON 字串放入 prompt，一次請求整篇文章；停用時沿用目前的 `ArticleSegmenter.split()` 分批翻譯流程。
- 將固定格式指示定義為程式常數，實際請求與 Preset 預覽共用同一份指示。

## 模型輸出契約與解析

模型必須只回傳純 JSON 陣列，不得有 Markdown code fence。陣列項目格式：

```json
[
  {"from": 1, "to": 5, "text": "第 1 至 5 句合併後的譯文"}
]
```

- `from`、`to` 是 1 起算且含頭含尾的句子索引。
- 每筆 `text` 是對應句子範圍的合併翻譯。
- 分段必須依序、連續、完整涵蓋句子清單，不得重疊、漏句或重排。
- 本機依索引從原始句子清單重建每段原文，建立既有 `ArticleSegment`；不要求模型重複輸出原文。
- JSON 格式錯誤、欄位型別錯誤、空譯文或索引範圍不合法時，視為解析失敗並顯示清楚錯誤；不得靜默退回一般翻譯。
- API 限制／上下文或輸出超限錯誤同樣明確呈現，讓使用者決定如何處理。

## 測試範圍

- 句子切分：句尾標點、中文／英文標點、未標點尾段保留及原文還原。
- Preset JSON：新欄位 round-trip、舊資料缺欄位預設關閉、內建 Preset 開關值保存、複製沿用。
- Prompt：分段提示的常數內容，且預覽與實際請求均在字彙表前插入；輸入文章為 JSON 句子陣列。
- Parser：合法結果重建原文分段；拒絕錯誤 JSON、非法或非連續索引、漏句、重複／重疊範圍及空翻譯。
- 翻譯流程：LLM 開關啟用時一次處理全文；關閉時維持現況；Google 不使用此功能；解析/API 失敗顯示錯誤且不回退。
- UI 測試以穩定 widget key 驗證互動與 routing，不以固定文字、動畫、位置或顏色做測試。

## 非目標

- Google 翻譯的分段行為。
- 自動重試、降級或自動把長文再次拆批。
- 由模型輸出原文文字或以行號定位原文分段。
